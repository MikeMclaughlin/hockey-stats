How grading works

  • Exact — projected away and home goals both match the official final.
  • Winner only — the score missed, but the projected winner was right.
  • Miss — both the score and the winner missed.
  • Pending — the game has not been graded yet.
  • Lock — the estimate updates when the model changes until puck drop (start time). After that it stays put, even if the live projection moves. Review shows the locked score beside the current model. A row marked “locked ≠ live” was frozen earlier (for example on Sep 10) and the model has since moved.
