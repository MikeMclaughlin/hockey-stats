How grading works

  • Exact — projected away and home goals both match the official final.
  • Winner only — the score missed, but the projected winner was right.
  • Miss — both the score and the winner missed.
  • Pending — the game has not been graded yet.
  • Grade — opening this page grades finished games for every visitor. The Grade finals button is a manual run and needs an admin sign-in.
  • Total error — absolute difference between projected total goals and actual total goals.
  • Margin error — absolute difference between the projected goal margin (away minus home) and the actual margin.
  • Range — 2026-27 so far, or the last 7 days ending on the NHL scoreboard date. Counts use graded games in that range only. If none are graded, the accuracy line says no graded games yet.
  • Edge vs market — the saved Edge pick (or the pick rebuilt from saved pre-game stats) against the saved moneyline favorite, and the locked total against the saved over/under. The card’s Toss-up label means the logistic win chance is under 55%. The previous Edge rule still leaves its own toss-up out of the firm-pick rate. Games with neither a moneyline nor a total are left out and counted on their own.
  • Lock — the estimate updates when the model changes until puck drop (start time). After that it stays put, even if the live projection moves. Review shows the locked score beside the current model. A row marked “locked ≠ live” was frozen earlier (for example on Sep 10) and the model has since moved.
